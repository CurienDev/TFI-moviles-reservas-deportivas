| Guía | Para qué sirve | Markdown | PDF |
|---|---|---|---|
| **1. Guía de estudio** | Entender la app por dentro: arquitectura, flujos, API, seguridad, persistencia, reglas y preguntas para la defensa. | [01-guia-de-estudio.md](01-guia-de-estudio.md) | [PDF](01-guia-de-estudio.pdf) |

Orden recomendado: **2 → 3 → 1** (instalar, probar usando la app, y después estudiar el código con la app ya conocida).

Los archivos `.md` se leen directo en GitHub; los `.pdf` tienen el mismo contenido para imprimir o leer en el celular.
Si se edita una guía, el `.md` es la versión de referencia.
